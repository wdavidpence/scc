## Design notes
- src2/engine/simRng.js: pure, seeded (sfc32 or mulberry32), state = 4x u32
  + counter; serialize/restore; nextU01, nextInt(n), range(a,b). No DOM/Phaser.
- BattleScene: create this.rng = SimRng.fromSeed(matchSeed) at battle init;
  matchSeed flows from lobby/settings/replay header (P1.035 will formalize).
- exportSimState must emit rngState (currently this.simRngState || 0 — wire
  the live counter/state in).
- 100-seed replay identity gate CANNOT fully run until P1.038 headless
  runner + P1.026 fixed-delta (variable delta still in update()). Interim
  gate: (a) PRNG stream identity across 100 seeds x two processes
  (default vs --jitless V8, same pattern as verify-int-coords), (b) source
  scan: sim files have zero Math.random, presentation allowlist unchanged,
  (c) seam: exportSimState includes seeded rngState, (d) scripted two-run
  equality for any pure helper extracted. Document deferral honestly in
  STATE done_when_result.
- Do NOT convert presentation random to seeded random yet — that mixes
  streams and re-couples render rate to sim. Separate ticket if ever.
