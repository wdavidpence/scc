  render dt via update(time, delta); input handlers mutate state instantly at
  event time. "Tick-stamped" therefore requires introducing the tick counter
  in the live scene (see scope rule 2).

- Non-mutators (leave immediate): cursor changes, ghost/snapGhost, camera
  wheel/zoom, audio select/deselect, _patrolPingAt, window.__inLog test log,
  music unlock (L172-173), coach.onDown swallow gate.

## Scope rule (proposed, same shape as P1.025/26 kernel pattern)
1. src2/engine/cmdQueue.js — pure kernel: push({tick, seq, player, cmd}),
   drainTo(tick) pops all entries with stamp <= tick in (tick, seq) order;
   no Phaser/DOM; deterministic under shuffled arrival.
2. Live tick counter: create this.simClock = new SimClock() in BattleScene
   init; in update(): advance(delta), simTickIndex += ticks, drain cmd queue
   after advance. This satisfies the deferred "scene consumption of the
   clock" note — it is NOT the full fixed-delta migration (that is the
   P1.029 mandated first task in BACKLOG; do not conflate).
3. Deletion quota 2: (a) pointerdown direct mutations (patrol setOrder,
   casts, tryPlace build order, autoTeamByPointer) become enqueued commands
   drained at tick boundary; (b) keyboard direct sim mutations (stance,
   burrow, autoMine, pause) become enqueued commands. Mode flags that only
   gate the NEXT gesture (castMode, scanMode, patrolMode, attackMoveMode)
   may stay immediate and documented — they address the queue, not the sim.
4. Selection stays immediate (presentation + input addressing). Anything
   that writes unit.order/unit.state/patrolPoints/energy/economy/team-control
   goes through the queue.

  must NOT execute while timeScale===0 — document: stamps taken on resume
  tick, or reject while paused (kernel gate covers either; pick one).
- 263-suite Playwright gates dispatch real mouse events; queue adds <=1 tick
  (~42 ms) latency before orders take effect. Poll-based checks survive;
  fixed-sleep checks may need +50 ms tolerance — check each edited gate.
- Hotseat activeTeam switch feeds WHO may act -> ordering-relevant, must be
  queued (stamped), not immediate.
- Drag-select on pointerup reads dragStart (presentation) — unaffected.
- v253 AudioContext env-flake is persistent on this machine (documented in
  P1.024 entry); suite control = pre-change bundle.
- ReplayScene/HotSeat replay paths: replay step loop must feed the same
  cmdQueue drain or replays desync by construction — check replay tick feed
  before wiring.
