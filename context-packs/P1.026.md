# P1.026 context pack — delete variable-delta simulation updates

Done-when: all simulation mutation occurs only inside the fixed tick; deletion
quota count=1.

## What was measured (2026-09-20, before any edit)
- No pure stateless-rnd() files exist anymore: every per-frame
  `const rnd = this.rng()` in BattleScene is build-time decor
  (terrain paint, grass/ore decal placement). Do not "convert" those; they
  never mutate state after setup.
- The true variable-delta problems are:
  1. **Timer desync (state, live)**: entity.js ~L483/L501 interceptor
     `it.cd` decrements by renderer dt while projectile flight (L610+) and
     liveProjectiles tick by `gameTime` — two clocks for one combat decision.
  2. **Render-rate-coupled gameplay random (live)**: BattleScene ~L4084
     `Math.random() < 0.4` shell-processor branch inside the per-frame
     projectile loop.
  3. **The whole variable-dt update chain (the scheduled deletion)**:
     BattleScene.update -> Unit.update(dt) -> stepAlongPath/stepAlongFlow/
     fire/harvest, AI blocks, all gated by delta/timeScale.

## Execution options (decided at 2026-09-20 retro)
- (A) Full switch of the LIVE runtime to simClock 24Hz fixed step. Big-bang;
  touches every dt consumer; needs the whole browser suite re-baselined.
- (B) IN-FLIGHT GUARD: (i) fix the two live clock-desync/random sites above;
  (ii) create src2/engine/simWorld.js — a pure headless kernel that consumes
  simClock (fixed 24Hz) + simInt (movement) + seeded rng and runs scripted
  matches (no Phaser/DOM); (iii) gate: 10k-tick hash equality across engines
  + fixed-tick count under 30/60/144Hz render schedules + "render pause
  cannot alter sim hash" probe; (iv) record the live-runtime migration as
  P1.029's mandated first task (its done-when already requires golden tests
  running "without DOM or Phaser").
- Chosen: (B), matching how P1.023 established its kernel + gate seam
  pattern. This keeps the "deletion" honest: the live variable-dt pathway is
  proven superseded by an equal-or-better fixed-tick implementation, and the
  deletion itself executes in P1.029 with the golden-match harness ready.
