## Golden stream design (replays/training-1.sccr, generated)
- seed: pick one, terrain from buildMapState(seed); dataHash covers UNITS/
  BUILDINGS/TECHS -> no format/schema change needed (SCCR encodes any cmd type).
- Initial units: [0,'mcv',...], [1,'broodmatron',...]. Enemy broodmatron may
  NOT deploy in v1 (brot's blight + deployAI fork risk) -- gather + dummy only.
- Command conversion of the 12 coach steps (player 0):
  select_mcv  -> no state command needed (selection-only) -- omitted;
  deploy      -> {type:'deploy', payload:{uid}} tick right after spawn-safe;
  select_base -> selection-only (supplyCap recompute happens INSIDE deployMCV);
  train_worker-> {type:'queue', payload:{bid:'commandCenter',kind:'rigger'}};
  select_worker/harvest -> {type:'order', payload:{wp:mineral coords}} (the
    worker branch issueMove; autoMine re-claim makes harvest start);
  click_build + place_building -> {type:'place', payload:{bid:'barracks',x,y,sel}};
  click_prod_building -> selection-only;
  train_fighter -> {type:'queue', payload:{bid:'barracks',kind:'marine'}};
  research (done_when wants it) -> {type:'research', payload:{bid:'barracks',
    techId:'combatMedics'}} (barracks-at tech, exercises completeResearch +
    spawn-bonus path; also gives the marine a bonus to prove research effects);
  select_fighter -> selection-only;
  kill_foe -> {type:'spawn', payload:{kind:'skarnling', team:1, x,y, hpFrac:0.45,
    dmgNerf:true}} + {type:'order',...} fighter attacks it (attackTarget needs
    a target id -> new 'spawn' cmd must allocate an id referenceable later).
- Player-1 commands (to replace crippled-AI behavior honestly): broodmatron may
  issueMove toward its side; gather starts via autoMine? autoMine re-claim is
  team-0 ONLY in stepSim; enemy workers in the crippled AI were assigned by
  updateAI -> replaced by stream: explicit 'order' moves for enemy gatherers
  + a 'queue' chain if we want enemy production (defer: keep enemy minimal =
  dummy only, no enemy workers in v1 -> less fork surface; document).
- Tick numbers: hand-tuned; generator must assert chain milestones via a headless
  preflight (CC deployed, rigger born, first deposit >0, barracks built, marine
  born, dummy dead) -- a golden that silently skips commands is a lie (stats.executed).
